Flet：用 Python 打造跨平台桌面、手機與網頁應用程式的終極利器

Flet 是一個革命性的開源框架，讓開發者只需要使用 Python 就能開發出可在 iOS、Android、Windows、macOS、Linux 和網頁上執行的應用程式。這個專案最大的特色是：你不需要任何前端開發經驗。

Flet 底層使用 Google 的 Flutter 框架來渲染 UI，提供超過 150 個內建的 UI 元件，包含 Material Design 和 Cupertino（iOS 風格）設計系統。這意味著你可以用純 Python 程式碼，打造出具有原生外觀與體驗的跨平台應用程式，完全不需要學習 Dart、Swift、Kotlin、HTML 或 JavaScript。
對於 Python 開發者來說，Flet 就像是 Electron 的替代方案，但更輕量、啟動更快，而且能夠真正實現「一次撰寫，到處執行」的願景
